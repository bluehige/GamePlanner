# Gameplay Balance Lab

밸런스를 감각적인 숫자 조정이 아니라 **가정, 공식, 기준 시나리오, 시뮬레이션, 실제 플레이 결과를 연결하는 실험**으로 다룬다.

## 사용 시점

- 전투 능력치, 성장 곡선, 가격, 보상, 확률, 쿨다운을 설계하거나 수정할 때
- 특정 유닛·빌드·전략이 지나치게 강하거나 약하다는 제보가 있을 때
- 신규 콘텐츠를 기존 진행 구간에 삽입할 때
- 난이도 곡선이나 경제 인플레이션을 검증할 때

## 입력

- Game Contract와 관련 시스템 계약
- 현재 수치 데이터와 계산식
- 목표 플레이 시간, 승률, 자원 흐름, 실패 비용
- 기준 플레이어 유형과 숙련도
- 실제 텔레메트리·플레이테스트가 있으면 해당 원자료
- 관련 Work Order와 Change Impact 보고서

## 절차

1. 밸런스 문제를 증상이 아니라 측정 가능한 질문으로 바꾼다.
2. 현재 공식, 단위, 반올림, 상한·하한, 랜덤 분포를 문서화한다.
3. 초반·중반·후반 및 정상·불리·유리 상태의 기준 시나리오를 만든다.
4. 각 시나리오의 기대 범위를 정의한다.
5. 자동 계산 또는 몬테카를로 시뮬레이션을 실행한다.
6. 핵심 변수의 민감도와 상호작용을 조사한다.
7. 지배 전략, 무의미한 선택, 회복 불가능 상태를 찾는다.
8. 가능한 최소 변경안을 비교한다.
9. 실제 엔진 빌드와 플레이테스트에서 모델 결과를 대조한다.
10. 차이가 크면 모델 가정이나 구현을 먼저 수정하고 숫자를 다시 맞춘다.

## 필수 지표

게임에 맞는 지표만 선택하되 최소한 다음 범주를 검토한다.

- 전투: 처치 시간, 생존 시간, 피해 효율, 슬롯 효율, 자원당 성능
- 경제: 유입·유출, 구매 가능 시점, 회수 기간, 인플레이션
- 성장: 구간별 증가율, 선택 간 격차, 소프트캡·하드캡
- 전략: 선택률, 성공률, 상성, 조합 시너지, 지배 전략
- 실패: 손실 크기, 복구 시간, 연속 실패 시 악화 정도
- 변동성: 평균뿐 아니라 분산, 극단값, 반복 재현 가능성

## 하드 게이트

- 한 번의 플레이 감상만으로 전체 수치를 변경하지 않는다.
- 승률 하나만으로 선택의 건강성을 판정하지 않는다.
- 목표 범위와 기준 시나리오 없이 숫자를 조정하지 않는다.
- UI 표시값과 실제 계산식을 따로 구현하지 않는다.
- 랜덤 시뮬레이션은 시드, 반복 횟수, 분포를 기록한다.
- 숫자 변경으로 구조적 설계 문제를 숨기지 않는다.

## 완료 게이트

- 모든 핵심 수치에 단위와 출처가 있다.
- 최소 세 구간 이상의 기준 시나리오가 있다.
- 제안 변경의 민감도와 극단값을 확인했다.
- 시뮬레이션 결과와 엔진 결과의 차이를 설명할 수 있다.
- 실제 재미·공정성 판단은 플레이테스트 증거와 분리되어 있다.
