# 04. 외부 스킬 정책

## 기본 정책

1. 외부 원본을 이 저장소에 그대로 복제하지 않는다.
2. 저장소·경로·commit SHA·라이선스·사용 단계를 lock 파일에 기록한다.
3. 어댑터는 입력 계약과 출력 계약만 정의하고 원본의 세부 절차를 재출판하지 않는다.
4. 외부 스킬이 없으면 내부 최소 절차로 강등하고 그 사실을 결과에 적는다.
5. upstream 갱신은 자동으로 따라가지 않는다. 변경 내역을 검토한 후 SHA를 갱신한다.
6. 라이선스가 명시되지 않은 자료는 개념 참고만 하고 문장을 복제하지 않는다.

## 왜 submodule이 아닌가

Agent Skill 환경마다 설치 위치와 로딩 방식이 다르고, 일부 원본은 큰 자산이나 실행 환경을 포함한다. GamePlanner는 중앙 통제와 재현성을 위해 버전 잠금 manifest를 사용하고, 실제 설치는 프로젝트 환경에서 수행한다.

## 외부 도구가 프로젝트 계약과 충돌할 때

프로젝트 계약이 우선한다. 외부 스킬이 범위를 확대하거나 데이터를 변경하도록 요구하면 그 동작을 거부하고 Work Order를 다시 작성한다.
