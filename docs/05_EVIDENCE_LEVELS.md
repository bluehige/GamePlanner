# 05. 증거 수준

| 수준 | 의미 | 예시 |
|---|---|---|
| E0 | 문서·코드만 보고 한 추정 | 정적 코드 리뷰 |
| E1 | 자동 정적 검사 | 스키마, lint, 참조 존재 검사 |
| E2 | 엔진 또는 빌드가 실제로 실행됨 | 씬 로드, 패키지 생성 |
| E3 | 실제 입력과 상태 전환을 재현 | 플레이 경로, 원증상, 저장·로드 왕복 |
| E4 | 목표 사용자 또는 대표 플레이테스트 | 관찰, 성공률, 시간, 오류 |
| E5 | 실제 배포 환경 검증 | 설치, 업데이트, 최소 사양 성능, 롤백 |

다음 표현은 E4 없이 확정하지 않는다.

- 직관적이다
- 재미있다
- 배우기 쉽다
- 플레이어가 이해한다

다음 표현은 E5 없이 확정하지 않는다.

- 출시 준비가 끝났다
- 최소 사양을 지원한다
- 이전 버전에서 안전하게 업데이트된다

버그 수정은 최소한 원래 재현 절차가 실패하지 않는 E3 증거와 관련 회귀 검사가 필요하다. 출시 판단은 기능 E3, 사용자 경험 E4, 배포 환경 E5를 각각 충족해야 한다.
